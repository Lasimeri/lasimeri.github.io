—— flows ——
the short-link round trip

  mint      /shrtlnk/ ── POST /s/go ──▶ crystal ── put short:id ──▶ r2
  reply     crystal ──▶ { id, https://seaof.glass/s/go/id }
  resolve   visitor ── GET /s/go/id ──▶ crystal ── get short:id ──▶ r2
  land      crystal ── 302 ──▶ /shrtlnk/r/?to=target ── click-through ──▶ target


client-side only · never talk to crystal

  /ittybitty/   the document lives in the url fragment
  /qii/         game data cached in indexeddb
  /tools/pgp    keys and plaintext never leave the tab
—— roles ——
/ · landing
the front door. one hand-written page, inline css, zero javascript. links to everything below and nothing else.
/sitemap/ · this page
the map you are reading, generated by sitemap/build.py: edit the data model, run it, commit the output. the diagram geometry is computed, never hand-aligned.
/ittybitty/ · the url is the document
an editor whose files live entirely in the link: content is lzma-compressed (and optionally encrypted) into the url fragment, so sharing the link is publishing. codemirror for editing, marked for markdown preview, qr export for handing a whole document to a phone, and a service worker that makes it installable and offline-capable. no server ever sees a byte of the document, because the fragment never leaves the browser.
/qii/ · quake ii
the qwasm2 engine compiled to webassembly, with gl1, gles3, and software renderers. jszip unpacks game data in the browser and indexeddb (qii-assets) caches the pak files, so the download happens once. after the first load it is a local game that happens to live at a url.
/shrtlnk/ · url shortener
the ui posts a url to /s/go and gets back seaof.glass/s/go/:id. resolving a short link never jumps straight to the target: crystal 302s to the /shrtlnk/r/ splash, which previews the destination behind a disclaimer and a deliberate click-through. no blind redirects.
/tools/ · seven single-file utilities
ip, headers, dns, ping, and whois are thin fronts for the matching /s/* route: the worker either reflects what it sees (your ip, your headers) or asks the outside world on your behalf (doh, rdap, a timed fetch). tmp drops a file into r2 with a one-hour expiry. pgp is the odd one out: it needs no server at all.
/tools/pgp/ · openpgp runtime
rust (the rPGP crate) compiled to wasm, executed inside a web worker so rsa-4096 keygen does not freeze the tab. keygen, encrypt, and decrypt all run locally; keys and plaintext never leave the page. the rust source ships alongside the built wasm, so the artifact is reproducible.
crystal · cloudflare worker
the only server code on the site: one typescript file behind seaof.glass/s/*. nine routes, rate-limited to 60 requests a minute per ip, cors locked to the site origin. it holds no logic beyond what the static pages cannot do themselves: reflecting network facts, fetching cross-origin, and touching storage.
r2 · sea-glass-store
the only state anywhere. short:* keys map ids to target urls and live forever; tmp:* keys hold uploads stamped with an expiry that is checked, and purged, on read. everything else on the site is stateless or client-side.
the repo · Lasimeri/lasimeri.github.io
both halves live in one repository. a push to main republishes the static site through github pages; wrangler deploy in worker/ republishes crystal. the two deploys are independent and meet only at the /s/* fetch boundary.
