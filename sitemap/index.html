sea of glass / sitemap

the site, its components, and how they fit together

—— the map ——
seaof.glass · click a node to expand it
├── github pages the static half
github pages serves this repo at seaof.glass (via CNAME). a push to main republishes the whole site; .nojekyll keeps the files verbatim. everything under this node is plain files: no build step, no server, no javascript unless a page brings its own.
│ ├── / landing page
the front door. one hand-written page, inline css, zero javascript. links to everything on the site and nothing else.
│ ├── /sitemap/ this page
the map you are reading, generated by sitemap/build.py: edit the data model, run it, commit the output. the dropdowns are native html <details> elements, so the page is still zero javascript.
│ ├── /ittybitty/ the url is the document
an editor whose files live entirely in the link: content is lzma-compressed (and optionally encrypted) into the url fragment, so sharing the link is publishing. codemirror for editing, marked for markdown preview, qr export for handing a document to a phone, and a service worker that makes it installable and offline-capable. no server ever sees a byte of the document: the fragment never leaves the browser.
│ ├── /qii/ quake ii
the qwasm2 engine compiled to webassembly, with gl1, gles3, and software renderers. jszip unpacks game data in the browser and indexeddb (qii-assets) caches the pak files, so the download happens once. after the first load it is a local game that happens to live at a url.
│ ├── /shrtlnk/ url shortener
the ui posts a url to /s/go and gets back seaof.glass/s/go/:id. resolving a short link never jumps straight to the target: crystal 302s to the splash below, which previews the destination and waits for a deliberate click. no blind redirects.
│ │ └── /shrtlnk/r/ redirect splash
the click-through page every short link lands on: shows the target url behind a disclaimer, sends no referrer, and is marked noindex. the deliberate click is the only way forward.
│ └── /tools/ seven single-file utilities
each tool is one html file. five of them are thin fronts for a matching /s/* route on crystal; tmp stores through crystal into r2; pgp needs no server at all.
│ ├── ip.html what is my ip
asks GET /s/ip; crystal echoes the connecting ip (the CF-Connecting-IP header) back as plain text.
│ ├── headers.html request inspector
asks GET /s/headers; crystal reflects every request header back as json, so you see exactly what a server sees.
│ ├── dns.html dns lookup
queries GET /s/dns/:type/:domain; crystal relays to cloudflare doh. allowed types: A, AAAA, MX, TXT, CNAME, NS, SOA.
│ ├── ping.html http ping
calls GET /s/ping/:url; crystal fetches the target with a 5 second abort and reports status, latency in ms, and response headers.
│ ├── whois.html rdap lookup
calls GET /s/whois/:domain; rdap via rdap.org with a verisign fallback for .com and .net.
│ ├── tmp.html temp file drop
uploads up to 10 mb via POST /s/tmp into r2. links live one hour; expired objects are purged the next time they are read.
│ └── pgp.html openpgp, in-browser
keygen, encrypt, and decrypt with no server involvement at all. the crypto runs in the wasm runtime below.
│ └── /tools/pgp/ rust→wasm runtime
rust (the rPGP crate) compiled to wasm, executed inside a web worker so rsa-4096 keygen does not freeze the tab. keys and plaintext never leave the page. the rust source ships alongside the built wasm, so the artifact is reproducible.
├── crystal cloudflare worker · /s/*
the only server code on the site: one typescript file (worker/src/index.ts) behind seaof.glass/s/*. rate-limited to 60 requests a minute per ip, cors locked to the site origin (plus localhost for dev). deployed with wrangler deploy, independent of the pages deploy. it holds no logic beyond what static pages cannot do themselves: reflecting network facts, fetching cross-origin, and touching storage.
│ ├── GET /s/ip reflect
returns the caller's ip as plain text.
│ ├── GET /s/headers reflect
returns the caller's request headers as json.
│ ├── GET /s/dns/:type/:domain lookup
doh relay to cloudflare-dns.com. allowed types: A, AAAA, MX, TXT, CNAME, NS, SOA.
│ ├── GET /s/ping/:url lookup
timed fetch of the target with a 5 second abort; reports status, milliseconds, and response headers.
│ ├── GET /s/whois/:domain lookup
rdap lookup via rdap.org, falling back to verisign for .com and .net.
│ ├── POST /s/go store
mints a random 6-hex-char id and stores short:id → url in r2.
│ ├── GET /s/go/:id store
resolves the id from r2 and 302s to the /shrtlnk/r/ splash; never a blind redirect.
│ ├── POST /s/tmp store
accepts up to 10 mb and stores it in r2 stamped with a one-hour expiry.
│ └── GET /s/tmp/:id store
serves the stored file; expired entries answer 410 and are deleted on read.
├── r2 · sea-glass-store the only state
everything else on the site is stateless or client-side; this bucket is the single place data rests. short:* keys map ids to target urls and live forever; tmp:* keys hold uploads stamped with an expiry that is checked, and purged, on read.
├── external services what crystal talks to
the outside world, reached only server-side by crystal on your behalf: cloudflare-dns.com for doh lookups, rdap.org and verisign for whois, and whatever target you point ping at. the browser never contacts these directly.
└── the repo Lasimeri/lasimeri.github.io
both halves live in one repository. a push to main republishes the static site through github pages; wrangler deploy in worker/ republishes crystal. the two deploys are independent and meet only at the /s/* fetch boundary.
