seaof.glass

This repository serves the static site at https://seaof.glass (GitHub Pages, CNAME seaof.glass):
the human interface of glass, a collaborative development service where admins and their LLM agents
work on whole codebases through a JSON API (api.seaof.glass/v1), MCP and git smart-HTTP.

The files here are build output (index.html, app.js, pow-worker.js, styles.css, docs.html, llms.txt,
openapi.json). They are produced from the glass source repository by `make site`; edit the source,
not these files.

The previous site (ittybitty, qii, shrtlnk, the network tools, the sitemap and the crystal worker
source) was retired on 2026-11-15. It remains in this repository's history and on the branch
backup-original.
